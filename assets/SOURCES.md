# Profile asset sources

- `profile-terminal.svg` and `profile-terminal-mobile.svg`: original SVG layout and motion, with ASCII characters derived locally from Bhavesh's existing portfolio portrait. No third-party portrait or profile design code was copied. `portrait.webp` retains the supplied portfolio photo for reproducible ASCII generation.
- `working-stack.svg`: original strip combining Devicon and Simple Icons logos already used by the portfolio. Their licences are in this folder.
- `contribution-calendar.svg`: actual GitHub contribution calendar from the GraphQL API. `scripts/update-activity.py` generates the asset; its snapshot period is visible in the graphic.

The reference profile informed the terminal/ASCII and contribution-graphic structure. All personal content comes from Bhavesh's current portfolio and public repositories.
